# Conector macho NPT pasamuros (pág. 21)

Conector recto: extremo tubo Swagelok + **rosca macho NPT con tuerca pasamuros** para
atravesar un panel. Tipo de racor `11` (`-X00-11-Y`).

## Referencia

- Base: `-X00-11-Y` (p. ej. `-400-11-4` = 1/4" tubo, NPT 1/4").
- Métrica: `-XM0-11-Y`.

## Dimensiones

| Letra | Significado |
|---|---|
| `A` | Longitud centro a extremo |
| `D` | Ø ext. del cuerpo |
| `E` | Paso mínimo interior |
| `F` | Entre caras del hexágono |
| Taladro panel | Ø del agujero en el panel |
| Espesor máx. | Espesor máximo de panel |
