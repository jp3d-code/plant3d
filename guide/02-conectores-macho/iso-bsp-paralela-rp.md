# Conector macho Rosca ISO/BSP Paralela (RP) (pág. 20)

Conector recto: extremo tubo Swagelok + **rosca macho paralela ISO 228** con cierre
**metal-metal** (tipo B). Sufijo `RP`.

Esta página incluye también los **racores taladrados** para termopares, tubos de
derrame y tes para intercambiadores de calor (ver
[`11-aplicaciones-especiales/taladrados.md`](../11-aplicaciones-especiales/taladrados.md)).

## Referencia

- Base: `-X00-1-YRP` (p. ej. `-400-1-4RP` = 1/4" tubo, rosca ISO 1/4").
- Métrica: `-XM0-1-YRP`.

## Dimensiones

| Letra | Significado |
|---|---|
| `A` | Longitud centro a extremo |
| `D` | Ø ext. del cuerpo |
| `E` | Paso mínimo interior |
| `F` | Entre caras del hexágono |
