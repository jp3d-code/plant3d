# 06 — Tapones y protectores

Piezas para cerrar extremos de racores, tubo o venteos.

## Notas de instalación

- **Tapón para tubo**: instalación como un racor Swagelok (apretar tuerca 1 1/4 vuelta,
  3/4 vuelta en tamaños pequeños).
- **Tapón para racor**: apretar 1/4 de vuelta (1/8 de vuelta en 2-4 mm / 1/16-3/16").
  No usar la galga de inspección.
- **Protector de venteo**: rosca NPT; se aprieta a mano + ligeramente con llave.
