# 05 — Tubos manguito conectores

Piezas rectas que conectan **tubo** a **tubería** (pipe): un extremo con férula mecanizada
(tipo Swagelok, para conectar a un racor hembra) y el otro extremo tipo adaptador a tubo.
Se entregan con tuerca y férulas preensambladas.
