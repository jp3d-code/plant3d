# Unión AN y Unión AN pasamuros (pág. 23)

Conector recto con extremo tubo Swagelok + **extremo abocardado AN 37°** (roscas
UNJF/UNJ). Usado en conexiones hidráulicas AN/JIC.

- **Unión AN** (`-X00-6-YAN`): extremo macho AN abocardado 37°.
- **Unión AN pasamuros** (`-X00-61-YAN`): atraviesa panel.

## Referencia

- Unión AN: `-100-6-2AN` (1/16" tubo, rosca 5/16-24), `-400-6-4AN`, etc.
- Pasamuros: `-400-61-4AN`, `-600-61-6AN`, etc.

## Dimensiones

| Letra | Significado |
|---|---|
| `A` | Longitud centro a extremo |
| `D` | Ø ext. del cuerpo |
| `E` | Paso mínimo interior |
| `F` | Entre caras del hexágono |
| `S` | Rosca AN (UNJF-3 / UNJ-3) |
