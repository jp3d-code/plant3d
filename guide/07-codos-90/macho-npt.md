# Codo macho NPT 90° (pág. 34)

racor `2`.

## Referencia

- Base: `-X00-2-Y` (p. ej. `-400-2-4` = 1/4" tubo, NPT 1/4").
- Métrica: `-XM0-2-Y`.

## Dimensiones

|---|---|
| `A` | Longitud centro a extremo |
| `D` | Ø ext. del cuerpo |
| `E` | Paso mínimo interior |
| `F` | Entre caras del hexágono |
