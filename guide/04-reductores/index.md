# 04 — Reductores

Racores que reducen de un diámetro de tubo a otro menor. Dos extremos tubo Swagelok de
distinto Ø. Se entregan con tuerca y férulas **preensambladas**.

## Dimensiones clave comunes

| Letra | Significado |
|---|---|
| `T` | Ø ext. tubo (extremo mayor) |
| `Tx` | Ø ext. tubo (extremo menor) |
| `A` | Longitud centro a extremo |
| `D` | Ø ext. del cuerpo (mayor) |
| `E` | Paso mínimo interior |
| `F` | Entre caras del hexágono |
| `G` | Entre caras (2º hexágono, >1") |

## Nota

- Hasta 1" / 25 mm: un solo hexágono (`F`). Más de 1": doble hexágono (`F` y `G`).
- Se entregan con tuerca y férulas preensambladas.
- El reductor largo solo se puede utilizar con conexiones hembra Swagelok.
