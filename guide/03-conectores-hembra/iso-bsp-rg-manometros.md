# Conector hembra ISO/BSP paralela (RG, manómetros) (pág. 28)

Racor recto: extremo tubo Swagelok + **rosca hembra ISO/BSP paralela RG** (para
manómetros). Sufijo `RG`.

## Referencia

- Base: `-X00-7-YRG` (p. ej. `-400-7-4RG` = 1/4" tubo, rosca ISO 1/4").
- Métrica: `-XM0-7-YRG`.

## Dimensiones

| Letra | Significado |
|---|---|
| `A` | Longitud centro a extremo |
| `D` | Ø ext. del cuerpo |
| `E` | Paso mínimo interior |
| `F` | Entre caras del hexágono |
