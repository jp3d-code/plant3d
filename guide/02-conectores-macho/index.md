# 02 — Conectores macho (tubo + rosca/soldadura)

Racores rectos con un extremo tubo (Swagelok) y el otro extremo **macho** (rosca o
preparado para soldar). La forma del cuerpo es la misma; cambia el tipo de conexión
del 2º extremo.

## Dimensiones clave comunes

| Letra | Significado |
|---|---|
| `T` | Ø ext. tubo (extremo Swagelok) |
| `A` | Longitud centro a extremo |
| `D` | Ø ext. del cuerpo |
| `E` | Paso mínimo interior |
| `F` | Entre caras del hexágono |

> Para racores taladrados (para termopares, tubos de derrame, etc.) se añade el sufijo
> `BT` a la referencia — ver [`11-aplicaciones-especiales/taladrados.md`](../11-aplicaciones-especiales/taladrados.md).
