# Adaptador a tubo macho AN (pág. 52)

Adaptador lineal: extremo tubo Swagelok + **rosca macho AN abocardada 37°** (UNJF-3 /
UNJ-3). Para conexiones hidráulicas AN/JIC.

## Referencia

- Base: `-X-TA-1-YAN` (p. ej. `-6-TA-1-6AN` = 3/8" tubo, AN 6).

## Dimensiones

| Letra | Significado |
|---|---|
| `A` | Longitud centro a extremo |
| `E` | Paso mínimo interior |
| `F` | Entre caras del hexágono |
