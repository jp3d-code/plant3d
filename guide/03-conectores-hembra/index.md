# 03 — Conectores hembra (tubo + rosca hembra)

Racores rectos con un extremo tubo (Swagelok) y el otro extremo **hembra** (rosca para
enroscar sobre una conexión macho). Tipo de racor `7`.

## Dimensiones clave comunes

| Letra | Significado |
|---|---|
| `T` | Ø ext. tubo (extremo Swagelok) |
| `A` | Longitud centro a extremo |
| `D` | Ø ext. del cuerpo |
| `E` | Paso mínimo interior |
| `F` | Entre caras del hexágono |

> Los racores RJ solo se fabrican en acero inoxidable.
