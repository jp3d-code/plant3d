# Te recta orientable (TST / TRT) (pág. 44-45)

Te con **un extremo recto roscado orientable** (con junta tórica):
- **TST** — rosca SAE/MS paralela.
- **TRT** — rosca ISO/BSP paralela.

## Referencia

- TST: `-X00-3TST` / `-X00-3-YTST`.
- TRT: `-X00-3TRT` / `-X00-3-YTRT`.

## Dimensiones

| Letra | Significado |
|---|---|
| `A` | Longitud centro a extremo (lado roscado) |
| `Ax` | Longitud centro a extremo (lado tubo) |
| `D` | Ø ext. del cuerpo |
| `E` | Paso mínimo interior |
| `F` | Entre caras del hexágono |
| `Fx` | Entre caras del extremo orientable |
| `U` | Ø ext. del retenedor |
