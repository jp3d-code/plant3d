# Tapón para racor (pág. 32)

Tapón roscado que se atornilla en el cuerpo de un racor Swagelok (cierra el extremo
roscado). Disponible para los mismos tamaños que el tapón para tubo.

## Referencia

- Base: `-X00-P` (p. ej. `-400-P` = 1/4", `-6M0-P` = 6 mm).

## Instalación

Mientras se sujeta firmemente el cuerpo del racor, apretar el tapón **1/4 de vuelta**
desde la posición apretada con los dedos. Para racores de 2, 3 y 4 mm; 1/16, 1/8 y
3/16": **1/8 de vuelta**. Para más de 25 mm / 1": 1/4 de vuelta.
**No usar la galga de inspección** en instalaciones de tapones para racor.
