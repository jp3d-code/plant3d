# Codo reductor 90° (pág. 36)

Codo de 90° con dos extremos tubo de **distinto diámetro** (T = mayor, Tx = menor).
Tipo de racor `2R`.

## Referencia

- Base: `-X00-2R-Y` (p. ej. `-600-2R-4` = 3/8" a 1/4").
- Métrica: `-XM0-2R-YM`.

## Dimensiones

| Letra | Significado |
|---|---|
| `T` | Ø ext. tubo (mayor) |
| `Tx` | Ø ext. tubo (menor) |
| `A` | Longitud centro a extremo |
| `D` | Ø ext. del cuerpo |
| `E` | Paso mínimo interior |
| `F` | Entre caras del hexágono |
