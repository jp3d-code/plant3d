# Conector macho Rosca ISO/BSP Paralela (RS) (pág. 19)

Conector recto: extremo tubo Swagelok + **rosca macho paralela ISO 228 / JIS B0202**.
Cierre con junta plana (disponibles en pág. 60). Sufijo `RS`.

## Referencia

- Base: `-X00-1-YRS` (p. ej. `-400-1-4RS` = 1/4" tubo, rosca ISO 1/4").
- Métrica: `-XM0-1-YRS`.

## Dimensiones

| Letra | Significado |
|---|---|
| `A` | Longitud centro a extremo |
| `D` | Ø ext. del cuerpo |
| `E` | Paso mínimo interior |
| `F` | Entre caras del hexágono |
