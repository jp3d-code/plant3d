# Codo orientable 90° (PR / ST) (pág. 37)

Codo de 90° con **rosca paralela orientable** con junta tórica: el extremo roscado se
puede orientar (girar) sin aflojar el sellado. Dos variantes:
- **PR** — rosca ISO/BSP paralela (ISO 228).
- **ST** — rosca SAE/MS paralela (SAE J1926/1, ISO 11926-1; solo acero al carbono e
  inoxidable).

## Referencia

- PR: `-X00-2-YPR`, métrica `-XM0-2-YPR`.
- ST: `-X00-2-YST`, métrica `-XM0-2-YST`.

## Dimensiones

| Letra | Significado |
|---|---|
| `A` | Longitud centro a extremo |
| `D` | Ø ext. del cuerpo |
| `E` | Paso mínimo interior |
| `F` | Entre caras del hexágono |
| `Fx` | Entre caras del extremo orientable |
| `U` | Ø ext. de la arandela/retenedor |
