# Juntas planas ISO/BSP (pág. 60)

Juntas planas para roscas ISO/BSP paralelas. Crean el cierre entre la rosca macho y el
puerto hembra.

## Variantes

| Tipo | Material | Racores |
|---|---|---|
| `CU` | Cobre | RP y RS |
| `NI` | Níquel | RG (manómetros) |
| `T` | PTFE | RJ |
| `RS` | Acero carbono con anillo FKM interior | RS |
| `RSD` | DIN 3852 (anillo exterior inox/carbono) | RS |
| `RSNB` | Anillo metálico 304L (DIN 7603 clase D) | RS |

## Referencia

- CU: `CU-Y-RP-2` (p. ej. `CU-4-RP-2` = 1/4").
- NI: `NI-Y-RG-2` (p. ej. `NI-4-RG-2`).
- PTFE: `T-Y-RJ-2` (estándar) y `T-Y-RJ-2-T` (gruesa).
- RS: `S-Y-RS-2V`; RSD: `SS-Y-RSD-2V`; RSNB: `304L-Y-RSNB-2`.
