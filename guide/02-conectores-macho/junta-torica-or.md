# Conector macho Cierre con junta tórica (OR) (pág. 22)

Conector recto: extremo tubo Swagelok + rosca con **junta tórica** para sellado.
Dos variantes:
- **SAE/MS paralela** con junta tórica (`-1-OR`).
- **NPT corta** con junta tórica (`-1-Y-OR`).

## Referencia

- SAE/MS: `-X00-1-OR` (p. ej. `-400-1-OR` = 1/4").
- NPT corta: `-X00-1-Y-OR` (p. ej. `-400-1-2-OR` = 1/4", NPT 1/8").

## Dimensiones

|---|---|
| `A` | Longitud centro a extremo |
| `D` | Ø ext. del cuerpo |
| `E` | Paso mínimo interior |
| `F` | Entre caras del hexágono |
