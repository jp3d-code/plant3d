# Codo para soldar 90° (pág. 38)

Codo de 90° con un extremo tubo Swagelok y el otro **preparado para soldar**:
- **Encastre** (socket weld) — `-9-...W`.
- **Tubería a tope** (butt weld, schedule 80) — `-2-...W`.

## Referencia

- Encastre: `-X00-9-YW` (p. ej. `-400-9-4W` = 1/4" tubo, soldadura 1/4").
- A tope: `-X00-2-YW` (p. ej. `-400-2-4W`).

## Dimensiones

| Letra | Significado |
|---|---|
| `A` | Longitud centro a extremo |
| `B` | Profundidad del encastre |
| `D` | Ø ext. del cuerpo |
| `E` | Paso mínimo interior |
| `F` | Entre caras del hexágono |
| `J` | Ø de la tubería |
| `K` | Ø del encastre |
