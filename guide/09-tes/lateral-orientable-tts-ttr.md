# Te lateral orientable (TTS / TTR) (pág. 44)

- **TTS** — rosca SAE/MS paralela.
- **TTR** — rosca ISO/BSP paralela.

## Referencia

- TTS: `-X00-3TTS` / `-X00-3-YTTS`.
- TTR: `-X00-3TTR` / `-X00-3-YTTR`.
