# Retenedor pasamuros (pág. 68)

Permite a **un solo instalador** apretar la contratuerca del lado A para iniciar la
instalación de un racor pasamuros; actúa como llave de sujeción mientras se conecta el
tubo a ambos lados A y B.

## Referencia

- Base: `SS-X2-61F` (p. ej. `SS-402-61F` = 1/4").
