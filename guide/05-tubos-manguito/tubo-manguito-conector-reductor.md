# Tubo manguito conector reductor (pág. 31)

Igual que el tubo manguito conector pero con el 2º extremo (adaptador) de menor
diámetro. Se entrega con tuerca y férulas preensambladas.

## Referencia

- Base: `-X00-PC-Y` (p. ej. `-401-PC-2` = 1/4" a 1/8").
- Métrica: `-XM1-PC-YM`.

## Dimensiones

| Letra | Significado |
|---|---|
| `T` | Ø ext. tubo (extremo mayor) |
| `Tx` | Ø ext. tubo del 2º extremo (menor) |
| `E` | Paso mínimo interior |
| `H` | Longitud total |
