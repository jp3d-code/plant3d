# Reductor largo (pág. 30)

Reductor con transición más larga. **Solo se puede utilizar con conexiones hembra
Swagelok.**

## Referencia

- Base: `-X00-RF-Y` (p. ej. `-600-RF-8` = 3/8" a 1/2").

## Dimensiones

| Letra | Significado |
|---|---|
| `T` | Ø ext. tubo (mayor) |
| `Tx` | Ø ext. tubo (menor) |
| `A` | Longitud centro a extremo |
| `D` | Ø ext. del cuerpo |
| `E` | Paso mínimo interior |
| `F` | Entre caras del hexágono |
