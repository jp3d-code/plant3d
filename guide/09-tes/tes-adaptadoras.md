# Tes adaptadoras (TAA / TTA / TAT / AAT) (págs. 42-43)

Tes que combinan conexiones de tubo Swagelok con **adaptadores a tubo** (extremos
roscados/soldados). Resuelven problemas de alineamiento y reducen stock.

## Variantes

| Sufijo | Nombre | Configuración |
|---|---|---|
| `TAA` | Adapter Tee | 2 rectas tubo + ramal adaptador |
| `TTA` | Adapter Branch Tee | Ramal adaptador (lateral) |
| `TAT` | Adapter Run Tee | Un extremo recto adaptador |
| `AAT` | Double Run Adapter Tee | Dos extremos rectos adaptadores |

## Referencia

- Base: `-X00-3-YTAA` / `-X00-3-YTTA` / `-X00-3-YTAT` / `-X00-3-YAAT`
  (p. ej. `-400-3-4TAA` = 1/4" tubo, adaptador 1/4").
